# Minecraft 26.x build and validation notes

The 26.x adapter is intentionally isolated under `versions/26.x` because Minecraft 26.1 switched Fabric projects to official Mojang names and a no-remap Loom workflow. It shares the fish database, data resources, loot pools, advancements, and progression behavior through `src/official26`.

Build a target with Java 25:

```powershell
cd versions/26.x
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-25.0.4.101-hotspot'
./gradlew.bat clean build -Pminecraft_version=26.3 -Ploader_version=0.19.5 -Pfabric_api_version=0.163.0+26.3 -Pmod_version=1.2.12 -Pjava_version=25
```

The reproducible sweep artifacts are copied to `V:/Development/Mods/Artifacts/Anglers-Odyssey-26.x` and are named `anglers-odyssey-1.2.12-mc-<minecraft-version>.jar`.

Automated build, 151-fish/69-advancement/resource validation, biome coverage, dedicated-server world bootstraps, and client bootstraps have passed for 26.1, 26.1.1, 26.1.2, 26.2, and 26.3. Manual fishing/journal smoke tests remain the release gate; no 26.x version is approved for public publication until those are complete.
