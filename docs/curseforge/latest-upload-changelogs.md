## 1.20.x changelogs

### 1.20.1

Restored the dedicated Minecraft 1.20.1 compatibility adapter while preserving the original Angler's Odyssey content. Includes 151 fish, biome-aware fishing, journal persistence, four-rod progression, advancement support, cast-state rod models, and the repaired advancement-screen scrolling behavior.

### 1.20.2

Added the Minecraft 1.20.2 Fabric compatibility adapter. Updated registry access, advancements, persistence, client screens, fishing integration, and resource loading while preserving all Angler's Odyssey gameplay content.

### 1.20.3

Added the Minecraft 1.20.3-compatible build using the shared pre-component adapter. Preserved all 151 fish, habitats, fishing pools, journal records, advancements, and rod progression.

### 1.20.4

Added the Minecraft 1.20.4-compatible build with version-qualified metadata and compatibility updates. Preserved the complete Angler's Odyssey fishing and progression experience.

### 1.20.5

Updated Angler's Odyssey for Minecraft 1.20.5's item-component era. Adapted item data, recipes, tooltips, persistence, networking, rendering, fishing behavior, advancement icons, and vanilla fishing-enchantment compatibility.

### 1.20.6

Updated the component-era adapter for Minecraft 1.20.6. Includes the corrected journal recipe result schema, component-based fishing data, vanilla rod-enchantment support, and dedicated-server compatibility validation.
